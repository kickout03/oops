# Real Interview Questions

### Q1 Why use friend function?

**Answer**

To allow an external function to access private members of one or more classes without making those members public.

---

### Q2 Can friend function be inherited?

**Answer**

No.

---

### Q3 Can friend function be virtual?

**Answer**

No, because it is not a member function.

---

### Q4 Can friend function access private variables?

**Answer**

Yes.

---

### Q5 Is friend function inside the object?

**Answer**

No.

It exists outside the class.
